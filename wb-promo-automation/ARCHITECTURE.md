# Архитектура системы

---

## Общая схема

```
┌─────────────────────────────────────────────────────────┐
│                    GitHub Actions                        │
│              (запуск каждый день в 06:00)               │
└────────────────────────┬────────────────────────────────┘
                         │
                    main.py
                         │
         ┌───────────────┼───────────────┐
         │               │               │
   wb_client.py   sheets_client.py   notifier.py
         │               │               │
         │               │               │
   WB REST API    Google Sheets      Telegram Bot
  (акции, цены)  (unit-экономика,   (уведомления
                  снимки, расчёты)   + Excel-файл)
         │
         ├── snapshot.py       (сравнение состояний)
         ├── calculator.py     (расчёт цен)
         ├── validator.py      (проверка правил)
         └── template_gen.py   (Excel-шаблон для WB)
```

---

## Поток данных (ежедневный запуск)

```
1. GitHub Actions → запускает main.py в 06:00
          │
2. wb_client.py → WB API
   GET /api/v1/calendar/promotions          (список акций на 30 дней вперёд)
   GET /api/v1/calendar/promotions/noms     (товары + planPrice по каждой акции)
   POST /api/v2/list/goods/filter           (текущие цены всех активных SKU)
          │
3. sheets_client.py → Google Sheets
   Читает: unit_economics (себестоимость, минимальная маржа)
   Читает: last_snapshot (вчерашнее состояние)
          │
4. snapshot.py
   Строит новый снимок из данных WB API
   Сравнивает с вчерашним → находит события:
     NEW_PROMO      — появилась новая акция
     PROMO_ENDING   — акция заканчивается через ≤3 дня
     PROMO_ENDED    — акция завершилась
     SKU_DROPPED    — товар выпал из акции
          │
5. calculator.py (только для NEW_PROMO событий)
   Для каждого товара в акции:
     minAllowedPrice = (себестоимость + логистика + упаковка)
                       / (1 - комиссия_WB)
                       / (1 - минимальная_маржа)
     calculatedPrice = max(planPrice, minAllowedPrice)
          │
6. validator.py
   Проверяет каждую рассчитанную цену:
   V001: цена не пустая
   V002: цена ≥ minAllowedPrice
   V003: цена ≥ текущая_цена / 3  (защита от карантина WB)
   V004: маржа ≥ 0
   V005: маржа ≥ желаемой (предупреждение)
   V006: скидка ≤ 95%
          │
7. template_generator.py
   Создаёт Excel-файл (только OK и WARNING товары)
   Формат: nmID | Цена | Скидка
          │
8. notifier.py → Telegram
   Отправляет сводку дня
   Прикладывает Excel-файл к сообщению
   Отдельные уведомления о заблокированных товарах
          │
9. sheets_client.py → Google Sheets
   Записывает: новый снимок → current_snapshot
   Записывает: рассчитанные цены → calculated_prices
   Добавляет: события → event_log
          │
10. Вы получаете Telegram-уведомление
    Проверяете Excel-файл (5 минут)
    Загружаете файл вручную на WB
```

## Обработка автоакций (особый случай)

WB переводит большинство акций в формат «автоакций». Для них endpoint
`/api/v1/calendar/promotions/nomenclatures` возвращает **пустой список** —
это задокументированное ограничение WB API.

**Решение:**
- Система дополнительно сравнивает фактические цены на WB (через `/api/v2/list/goods/filter`)
  с ценами из последнего снимка
- Если цена снизилась без нашего действия → событие `AUTO_PROMO_DETECTED`
- Уведомление в Telegram: «Похоже WB применил автоакцию. Проверьте ЛК."

## Технологический стек

| Компонент | Технология | Обоснование |
|-----------|-----------|-------------|
| Язык программирования | Python 3.11 | Простой синтаксис, богатая экосистема библиотек |
| База данных / UI | Google Sheets | Вы уже умеете работать с таблицами. Данные видны и редактируемы без кода |
| Уведомления | Telegram Bot | Бесплатный, работает на телефоне, поддерживает отправку файлов |
| Планировщик | GitHub Actions | Бесплатный cron, не нужен отдельный сервер |
| Хранилище кода | GitHub | Бесплатно, история изменений, удобный деплой |
| HTTP-запросы | `requests` | Стандартная Python библиотека |
| Google Sheets из Python | `gspread` | Простая и популярная библиотека |
| Генерация Excel | `openpyxl` | Стандарт для работы с xlsx в Python |
| Telegram из Python | `python-telegram-bot` | Самая популярная библиотека для Telegram |
