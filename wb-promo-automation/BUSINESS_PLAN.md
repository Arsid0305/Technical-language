# Бизнес-план: Автоматизация акций Wildberries

---

## 1. Суть задачи

Селлер Wildberries ежедневно тратит 1.5–2 часа на рутинные операции:

| Операция | Время сейчас | После автоматизации |
|----------|-------------|---------------------|
| Проверка новых акций на WB | 20 мин/день | 0 (автоматически) |
| Расчёт цен под каждую акцию | 40 мин/день | 0 (автоматически) |
| Заполнение шаблона загрузки | 30 мин/день | 0 (автоматически) |
| Финальная проверка и загрузка | 10 мин/день | 5 мин/день |
| **Итого** | **~100 мин/день** | **~5 мин/день** |

**Экономия: ~95 минут в день = ~47 часов в месяц.**

---

## 2. Что делает система

1. Каждый день в 06:00 автоматически проверяет акции на WB через официальный API
2. Сравнивает с вчерашним состоянием — находит новые и заканчивающиеся акции
3. Берёт себестоимость товаров из вашей таблицы (Google Sheets)
4. Рассчитывает оптимальную цену с учётом минимальной маржи
5. Проверяет, что цена не убыточна и не попадёт в карантин WB
6. Формирует готовый Excel-файл для загрузки на WB
7. Отправляет в Telegram: «Новая акция. Шаблон готов. Проверьте и загрузите.»
8. Вы проверяете за 5 минут → загружаете файл вручную на WB

---

## 3. Ключевые принципы

- **Система считает и предупреждает. Человек принимает финальное решение.**
- Ни одна цена не уходит на WB без вашего подтверждения (этап 1)
- Все заблокированные товары сопровождаются чёткой причиной блокировки
- Если что-то пошло не так — вы узнаёте об этом в Telegram, а не из упавшей маржи

---

## 4. Риски и защита

| Риск | Вероятность | Защита в системе |
|------|-------------|------------------|
| Убыточная цена ушла на WB | Низкая | Validation layer блокирует, товар не попадает в шаблон |
| Карантин цен WB (цена снижена в 3+ раза) | Низкая | Проверка: новая цена ≥ текущая / 3 |
| Товар выпал из всех акций | Средняя | Уведомление «нет следующей акции» за 3 дня |
| Автоакция WB применилась незаметно | Средняя | Мониторинг фактических цен через API |
| WB изменил структуру API | Низкая | Модульная архитектура — правка в одном файле |
| Устаревшая себестоимость в таблице | Средняя | Предупреждение при расчёте + ручное обновление |

---

## 5. Этапность

### Этап 1 — MVP (6 недель)
- Мониторинг акций
- Расчёт цен
- Генерация Excel-шаблона
- Telegram-уведомления
- **Загрузка: вручную**

### Этап 2 — Автозагрузка (после 2–3 месяцев работы Этапа 1)
- Кнопка «Подтвердить» в Telegram → цены уходят на WB через API
- Rollback: отмена загрузки если что-то пошло не так
- История изменений цен

### Этап 3 — Аналитика
- Сравнение с конкурентами
- Отчёты по эффективности акций
- AI-рекомендации по ценообразованию
