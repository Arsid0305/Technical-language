# Структура проекта и план разработки по неделям

---

## Файловая структура репозитория

```
wb-promo-automation/
│
├── .github/
│   └── workflows/
│       └── daily_run.yml          ← Автозапуск в GitHub Actions
│
├── src/
│   ├── __init__.py                ← Пустой файл (нужен для импортов)
│   ├── wb_client.py               ← Модуль 1: все запросы к WB API
│   ├── sheets_client.py           ← Модуль 2: чтение/запись Google Sheets
│   ├── snapshot.py                ← Модуль 3: снимки состояния и события
│   ├── calculator.py              ← Модуль 4: расчёт промо-цен
│   ├── validator.py               ← Модуль 5: проверка правил
│   ├── template_generator.py      ← Модуль 6: генерация Excel-шаблона
│   └── notifier.py                ← Модуль 7: Telegram-уведомления
│
├── main.py                        ← Точка входа, оркестратор
├── config.py                      ← Читает переменные окружения
├── requirements.txt               ← Список Python-библиотек
└── README.md                      ← Инструкция по запуску
```

import os

## План разработки: 6 недель

### Неделя 1: Фундамент и WB API

**Цель:** Подключиться к WB API и получить первые данные.

**Задачи:**
- [ ] Создать репозиторий на GitHub, добавить `.gitignore`
- [ ] Создать виртуальное окружение Python (`python -m venv venv`)
- [ ] Установить библиотеки: `pip install requests`
- [ ] Написать `config.py`
- [ ] Реализовать `wb_client.py`: метод `get_promotions()`
- [ ] Проверить: запустить скрипт, убедиться что список акций приходит
- [ ] Реализовать `wb_client.py`: методы `get_promo_nomenclatures()`, `get_current_prices()`
- [ ] Добавить паузы между запросами и retry-логику при 429

**Результат недели:** В консоли виден список акций WB с датами и планируемыми ценами.

---

### Неделя 2: Google Sheets

**Цель:** Читать unit-экономику из таблицы и записывать данные обратно.

**Задачи:**
- [ ] Создать Google Sheets таблицу по структуре из `SHEETS_STRUCTURE.md`
- [ ] Настроить Google Cloud: создать проект, включить Sheets API, создать сервисный аккаунт
- [ ] Установить библиотеки: `pip install gspread google-auth`
- [ ] Реализовать `sheets_client.py`: метод `get_unit_economics()`
- [ ] Заполнить тестовые данные в лист `unit_economics` (3–5 товаров для теста)
- [ ] Реализовать методы `write_snapshot()`, `append_event()`, `get_setting()`, `update_setting()`
- [ ] Проверить: скрипт читает таблицу, выводит себестоимость в консоль

**Результат недели:** Скрипт читает данные из Google Sheets и может записывать строки обратно.

---

### Неделя 3: Снимки и расчёт цен

**Цель:** Определять события акций и считать промо-цены.

**Задачи:**
- [ ] Реализовать `snapshot.py`: `build_snapshot()` и `detect_events()`
- [ ] Написать тесты для `detect_events()` (проверить все типы событий)
- [ ] Реализовать `calculator.py`: `calculate_promo_price()`
- [ ] Написать тесты для калькулятора (граничные случаи: цена = себестоимость, нулевая маржа)
- [ ] Связать модули в `main.py`: читаем данные → строим снимок → считаем цены → выводим в консоль

**Результат недели:** Скрипт рассчитывает промо-цены и показывает результат в консоли.

---

### Неделя 4: Валидация и Excel-шаблон

**Цель:** Проверять цены и формировать файл для загрузки.

**Задачи:**
- [ ] Реализовать `validator.py` со всеми 6 правилами
- [ ] Написать тесты: цена ниже минимальной, цена в 4 раза ниже текущей, отрицательная маржа
- [ ] Установить библиотеку: `pip install openpyxl`
- [ ] Реализовать `template_generator.py`
- [ ] Проверить: запустить скрипт, убедиться что Excel-файл создаётся с правильными данными
- [ ] Цветовое форматирование: OK — зелёный, WARNING — жёлтый (опционально)

**Результат недели:** На рабочем столе появляется готовый Excel-файл с промо-ценами.

---

### Неделя 5: Telegram и интеграция

**Цель:** Полный пайплайн работает на локальном компьютере.

**Задачи:**
- [ ] Создать Telegram-бота через @BotFather
- [ ] Установить библиотеку: `pip install python-telegram-bot`
- [ ] Реализовать `notifier.py`: все 5 типов уведомлений
- [ ] Финальная сборка `main.py`: связать все 7 модулей
- [ ] Запустить полный пайплайн, проверить каждый шаг
- [ ] Проверить все 11 тестовых сценариев из ТЗ
- [ ] Исправить найденные баги

**Результат недели:** Система полностью работает локально, все уведомления приходят в Telegram.

---

### Неделя 6: Деплой и автозапуск

**Цель:** Система работает автоматически без участия программиста.

**Задачи:**
- [ ] Создать `.github/workflows/daily_run.yml`
- [ ] Добавить все секреты в GitHub Settings → Secrets → Actions
- [ ] Запустить workflow вручную (кнопка `workflow_dispatch`) — проверить работу
- [ ] Убедиться что скрипт работает на GitHub Actions (не только локально)
- [ ] Написать `README.md`: инструкция по первичной настройке для не-программиста
- [ ] Подождать 3 дня автоматических запусков — убедиться что cron работает
- [ ] Передать заказчику документацию и провести финальный тест

**Результат недели:** Система работает автономно каждый день, результаты приходят в Telegram.

3. Доступ к Google аккаунту для настройки (или создаёт сервисный аккаунт сам)
4. Токен Telegram-бота
5. Заполненный лист `unit_economics` с реальными данными по SKU
6. Категорию товаров на WB (для уточнения размера комиссии)
7. Актуальную стоимость логистики WB для ваших товаров
